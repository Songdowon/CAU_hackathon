# S02 Layer-selective Unlearning Implementation Plan

**Goal:** Compare fixed layer masks against CE-gradient-ratio block selection, keeping the r014 training objective unchanged.
**Architecture:** S02.py provides tested masks and a bounded probe, then delegates training to the unchanged the frozen S02_reference.main by temporarily replacing its set_trainable function in this process. Existing GPU-locking runner remains the entry point.
**Tech stack:** Python, PyTorch, PyYAML, unittest.
**Spec:** User's S02 proposal; details and controls below.

## Constraints and controls
- All experiments start from m_o/M_o.pt; use released training split only for probes and learning.
- Keep configs/r014.yaml seed, training losses, learning rate, steps and data parameters for controlled comparisons.
- Fixed last-2/4/6/8 variants all include final norm and head. Additional last2 with head frozen, classifier-only (norm frozen), and all-parameter controls disambiguate the proposed overlapping cases.
- Adaptive S02 selects six eligible blocks by mean forget CE gradient norm / (mean retain CE gradient norm + 1e-8), then also trains norm/head.
- Probe eight batches of 32 images per split from independent loaders, in eval mode, without optimizer steps; restore parameter flags, individual module modes and Python/NumPy/CPU/CUDA RNG state.
- Ratios are a heuristic; save norms, variability, low-signal flags, masks, parameter counts, configuration and source hashes. Head-only cannot directly change the pre-logits representation.
- Preserve S01.py, unlearn.py, teammate code and existing artifacts. Refuse artifact overwrites.
