# S04 Gradient Surgery implementation plan

Goal: Test whether removing conflicting forget gradients improves the retain/forget representation tradeoff relative to an identical two-gradient control.
Design: One-way global projection over all trainable parameters. For d=dot(g_r,g_f)<0 and norm(g_r)>=1e-8, use g_f'=g_f-d/dot(g_r,g_r)*g_r, then g=g_r+g_f'. Keep r017 loss, data, seed, layer mask, optimizer, clipping, and 4800 steps unchanged. This is PCGrad-inspired and does not promise monotonic retain loss/CKA or private improvement under AdamW.
