# S03 trajectory averaging implementation plan

Goal: Run one r017-matched unlearning trajectory and compare last iterate, two tail EMAs, and four-checkpoint arithmetic average.
Architecture: Freeze the proven training loop in S03_reference.py with an optional post-optimizer callback; S03.py observes weights without feeding averages into training; tools/S03_run.py uses the existing GPU-locking runner and evaluates siblings in separate processes.
Tech stack: existing Python 3.12, PyTorch 2.8, timm, YAML. No new dependencies.
Spec: User's explicit S03 EMA/checkpoint averaging request and the in-chat design on 2026-09-05.

Constraints: original M_o initialization; r017 seed 0, last 6 blocks + norm/head, AdamW lr 3e-5, 4800 steps, identical loss/data. No M_o interpolation. No validation in training. No changes to teammate sources or restored template. Existing artifacts must never be overwritten. Shared GPU lock before every GPU subprocess. Public and private results stay distinct; no automatic official submission.
