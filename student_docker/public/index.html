제출 검증 API

제출 전 체크포인트가 채점 서버와 동일한 조건(strict=True 로드)으로 로드되는지 확인하는 API입니다. Swagger UI에서 POST /api/validate를 바로 호출해볼 수 있습니다.

📖 Swagger UI 열기 📑 ReDoc 열기

ℹ️ POST /api/validate는 빠른 구조 검사입니다. 공개 validation 점수는 터미널에서 python score_model.py models/실험이름.pt로 확인하세요. 이 점수나 validation 데이터는 외부로 전송되지 않습니다.

API 인증 필수

  • • 모든 API 엔드포인트 호출 시 사전에 제공된 API Key가 필요합니다.
  • • Swagger UI로 테스트 시 Authorize 버튼을 클릭하여 API Key를 입력하세요.
  • • 직접 API 호출 시 요청 헤더에 X-API-Key를 반드시 포함하세요.
  • • API Key 분실 시 진행요원에게 문의하세요.

개발 환경

브라우저에서 바로 사용할 수 있는 VS Code 개발 환경입니다. Unlearning 알고리즘 구현, 학습, 제출 검증을 이 안에서 전부 수행합니다.

💻 code-server 열기

개발 환경 정보:

  • • Python 3.10 + PyTorch 2.2.0 (채점 서버와 동일한 버전 고정)
  • • GPU 1장 할당 (CUDA 12.1 + cuDNN 8)
  • • 시작 모델(M_o), released 학습 세트, 단일 validation 제공
  • • ⚠️ 대회 규정 확인

접속 인증 필수

  • • code-server 접속 시 사전에 제공된 비밀번호를 입력해야 합니다.
  • • 비밀번호를 분실한 경우 진행요원에게 문의하세요.

🏆 모델 제출

로컬 validation으로 선택한 models/*.pt 하나를 중앙 채점 서버에 제출합니다. 중앙 서버가 비공개 test로 AUS와 RUS_o를 계산합니다.
팀당 최대 10회이며, 각 제출은 submissions/<submission_id>.pt에 고정됩니다.

/workspace/models 바로 아래의 파일명만 입력하세요. 실험마다 다른 이름을 권장합니다.

API Key(Swagger 인증용)와는 다른 값입니다. 팀에 발급된 제출 비밀번호를 입력하세요.

🏗️ 제출 형식

  • • 아키텍처: M_o와 동일한 ViT-Base/16-224 구조여야 하며, validate_submission.py의 strict=True 로드를 통과해야 합니다.

📚 데이터 제약사항

  • • released는 학습용, validation은 로컬 검증용입니다. 최종 test 데이터는 참가자 환경에 제공되지 않습니다.
  • • 잊어야 할 10개 클래스는 es/es_imagenet_mo/forget10.json에 명시되어 있습니다. 나머지 90개 클래스 성능은 최대한 보존해야 합니다.
